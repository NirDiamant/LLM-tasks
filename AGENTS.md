# AGENTS.md

Guidance for AI coding agents working in this repository. Humans are welcome to read it too; it is plain Markdown and GitHub renders it.

> **Status: archived.** Last meaningful change March 2024. This repository is kept as a record and is not maintained.
> Do not expect its dependencies to resolve or its code to run on a current stack without work.

## What this repository is

A graded collection of hands-on tasks for learning to work with large language models, organized
into difficulty levels (`Level 0`, `Level 1`) plus a standalone Harry Potter RAG notebook built on FAISS.
Each task is a self-contained exercise rather than a finished implementation.

- Canonical URL: https://github.com/NirDiamant/LLM-tasks
- Author: Nir Diamant

## Layout

| Path | What lives there |
| --- | --- |
| `Level 0/`, `Level 1/` | Tasks grouped by difficulty. |
| `RAG_FAISS_Harry_Potter.ipynb` | A worked RAG example over the Harry Potter text using FAISS. |

## Working here

- **These are exercises, not reference implementations.** Some are deliberately incomplete so a learner fills them in. Do not 'fix' an intentionally open task into a finished solution without checking which it is.
- The repository predates the author's later, much larger teaching repositories. For current RAG material use [RAG_Techniques](https://github.com/NirDiamant/RAG_Techniques) instead.
